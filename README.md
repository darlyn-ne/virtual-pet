# Virtual Pet Companion

A small virtual pet companion designed to bring a little life and comfort to your desktop. Built with HTML, CSS, and JavaScript, the project combines animated pet interactions, customizable environments, and simple productivity features in a cozy, interactive interface.

## Features

- **Animated Virtual Pet** — The pet can display different animations, including standing, walking, reading, eating, and sleeping.
- **Customizable Skins** — Switch between different pet skins to personalize your companion.
- **Interactive Pet** — Click on him to trigger special animations and sound effects.
- **Dynamic Window** — The window scenery changes according to the current season and time of day.
- **Customizable Environments** — Choose between different backgrounds to create your preferred atmosphere.
- **Live Clock and Date** — Keep track of the current time and date directly in the pet scene.
- **Pomodoro Timer** — Use the built-in timer with multiple duration options to support focused work sessions.
- **Sound Effects** — Enjoy audio feedback when interacting with buttons and the pet.
- **Persistent Preferences** — Selected backgrounds and pet skins are saved using `localStorage`, so your preferences are preserved when you reopen the app.

## Built With

- HTML5
- CSS3
- JavaScript (ES Modules)
- `localStorage` for persistent preferences
- HTML Audio API for sound effects
- Animated GIFs for pet animations

## Getting Started

### Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension if you don't already have it.
4. Open `index.html` with Live Server.

Running the project through a local server is recommended because the application uses JavaScript ES modules.

## Project Goals

This is a personal learning project created to practice front-end development while exploring interactive UI design, modular JavaScript, event handling, and browser APIs.

Future improvements may include expanding the pet's interactions, adding more customization options, and exploring a standalone desktop version.
